# Núcleo de Termografia

**Um novo olhar para termografia.**

Espaço de referência sobre termografia infravermelha: o que é, onde é usada (saúde, veterinária, indústria, construção civil, hidráulica e eletrônica), pesquisa sobre a temperatura do canto interno do olho, resenhas, manuscritos e artigos comentados.

Site: https://www.nucleodetermografia.com.br
